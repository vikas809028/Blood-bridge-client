# Blood Bridge Client

Blood Bridge Client is the frontend application for the Blood Bridge platform—a web solution designed to connect blood donors, recipients, and blood banks efficiently and securely. This repository contains the user interface and client-side logic for interacting with the Blood Bridge backend API, providing a seamless experience for users in need of blood donations or those willing to help.

## 🌟 Overview

Blood Bridge Client offers an intuitive and responsive interface for user registration, donor-recipient matching, blood request management, and real-time notifications. Built with modern web technologies, it ensures accessibility, usability, and reliability for healthcare and emergency scenarios.

## 🚀 Tech Stack

- **Frontend Framework:** React.js
- **State Management:** Redux / Context API
- **Styling:** CSS3, Styled Components, Bootstrap
- **API Integration:** Axios / Fetch
- **Other:** Responsive design, form validation, notifications

## 🛠️ Features

- User registration and authentication
- Donor and recipient profile creation and management
- Blood request submission and status tracking
- Real-time notifications and updates
- Blood bank search and information
- Admin dashboard (if included)
- Accessible and mobile-friendly design

## 📦 Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/vikas809028/Blood-bridge-client.git
    cd Blood-bridge-client
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Create a `.env` file with the backend API URL and other required variables.
4. Start the development server:
    ```bash
    npm start
    ```
5. Open `http://localhost:3000` in your browser to access the app.

## 📌 Usage

- Register or log in to create your profile.
- Browse, request, or donate blood as per your needs.
- Track requests, get notified, and manage your account via the dashboard.
